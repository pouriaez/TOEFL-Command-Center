# TOEFL Command Center

سامانه مدیریت آمادگی تافل با دو رابط مستقل:
- **نسخه وب:** `web_app.py` با Streamlit، قابل اجرا در مرورگر
- **نسخه دسکتاپ ویندوز:** `main.py` با PySide6

## اجرای نسخه وب

Python 3.11 یا جدیدتر:

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
streamlit run web_app.py
```

سپس `http://localhost:8501` را در مرورگر باز کنید.

## قابلیت‌های نسخه وب

- داشبورد پیشرفت، ساعت‌های هدف و آخرین نمره آزمون
- برنامه روزانه: افزودن، ویرایش، حذف و ثبت وضعیت انجام
- کارنامه آزمون‌ها: ثبت نمرات چهار مهارت و نمره کل، روند و CSV
- یادداشت‌ها و تحلیل خطا
- ورود فایل Excel فارسی از طریق مرورگر
- دانلود نسخه پشتیبان SQLite
- رابط راست‌چین فارسی و واکنش‌گرا

## اجرای نسخه دسکتاپ Windows

روی `run_windows.bat` دوبار کلیک کنید. این فایل وابستگی‌های `requirements-desktop.txt` را نصب می‌کند و `main.py` را اجرا می‌کند. برای ساخت EXE، پس از اجرای اولیه، `build_exe.bat` را اجرا کنید.

## استقرار روی Streamlit Community Cloud

مخزن را متصل و فایل اصلی را `web_app.py` انتخاب کنید. وابستگی‌های نسخه وب در فایل ریشه `requirements.txt` تعریف شده‌اند.

**پایداری داده‌ها:** برنامه به‌صورت پیش‌فرض از `data/toefl.db` استفاده می‌کند. در محیط‌های ابری با فایل‌سیستم موقت، برای حفظ دائمی اطلاعات باید `TOEFL_DB_PATH` را به فضای ذخیره‌سازی پایدار متصل کنید. این نسخه هنوز احراز هویت و پایگاه داده چندکاربره ندارد؛ برای انتشار عمومی، آن‌ها باید جداگانه اضافه شوند.

## داده‌های نسخه دسکتاپ

نسخه وب از همان ساختار SQLite و ماژول `workbook_importer.py` استفاده می‌کند، اما پایگاه داده پیش‌فرض وب با دیتابیس دسکتاپ یکی نیست. برای انتقال اطلاعات قبلی، فایل Excel را در بخش «تنظیمات و ورود Excel» وارد کنید یا نسخه پشتیبان را به مسیر پایگاه داده وب منتقل کنید.
